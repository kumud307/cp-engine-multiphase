### B. Only affect Cp − Cv (Route C via Cv) and the Cv estimate (15)

Cp − Cv = Tvα²/κ_T. For solids this is below 1 % of Cp (e.g. Al₂O₃: 5 J/(kg K) of 773), so even a 50 % error in α or κ_T changes Cp by under 1 %. For liquids it is 1–10 % of Cp, so a κ_T error matters only when Cp is computed from a measured Cv.
